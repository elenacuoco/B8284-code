# Demo — the first three minutes

`gw150914_first_look.ipynb` is the notebook shown in the first class: the
strain recorded on 14 September 2015, whitened, band-passed, and seen in time
and frequency. It runs in about a minute and needs nothing but this
repository.

The data in `data/` is the public LIGO release, 32 s at 4096 Hz from each
detector, from
[GWOSC](https://gwosc.org/eventapi/html/GWTC-1-confident/GW150914/), release
R1. It is committed here so the notebook runs with no network.

You meet all of this again, in full and with the analysis done properly, in
the laboratories of the course.
